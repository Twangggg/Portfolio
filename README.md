# Portfolio — Backend Developer

Interactive portfolio website built with React, featuring a terminal-style UI and 3D background.

## Tech Stack

- **React 19** + **Vite**
- **Tailwind CSS** — styling
- **React Router** — routing
- **React Helmet Async** — SEO
- **Spline** — 3D interactive background

## Features

- Terminal emulator as a navigation command interface
- ASCII art banner on terminal start
- Sections: Hero, About, Skills, Projects, Contact, FAQ
- 3D model background via Spline
- Command palette for quick navigation
- Project detail pages

## Getting Started

```bash
npm install
npm run dev
```

## Commands

| Command     | Description                    |
|-------------|--------------------------------|
| `help`      | Show available commands        |
| `about`     | About me                       |
| `skills`    | My skills                      |
| `projects`  | List projects                  |
| `contact`   | Contact info                   |
| `whoami`    | Display author info            |
| `clear`     | Clear terminal                 |

## Build

```bash
npm run build
npm run preview
```
